# Retail Sales Data Analysis Dashboard

## Overview
A beginner-friendly data analytics project exploring retail sales data using Python. The project analyzes sales trends, product performance, and profitability to identify business insights.

## Tools Used
- Python
- Pandas
- Matplotlib
- Google Colab

## Key Performance Indicators
| Metric | Result |
|---|---:|
| Total Sales | 2,297,200.86 |
| Total Profit | 286,397.02 |
| Unique Orders | 5,009 |
| Unique Products | 1,850 |
| Overall Profit Margin | 12.47% |

## Key Findings
- Technology generated the highest total profit among the three product categories.
- Furniture had the lowest category profit margin at 2.49%.
- November 2017 had the highest monthly sales in the analyzed dataset.
- The Canon imageCLASS 2200 Advanced Copier ranked first by total sales value.

## Project Workflow
1. Loaded and explored the dataset.
2. Checked for missing values and duplicate records.
3. Prepared date fields and cleaned duplicate rows.
4. Analyzed sales by month, category, product, and region.
5. Calculated business KPIs and profit margins.
6. Created charts and summarized business recommendations.

## How to Run
1. Open the `.ipynb` notebook in Google Colab.
2. Upload the required CSV dataset.
3. Check the CSV file path.
4. Run the cells in order.
